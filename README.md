# 网页收藏 · EdgeEver 插件

提取文章正文，预览确认后保存到 EdgeEver。保留标题、段落、列表、引用、表格、代码、链接和图片地址。

## 安装

在 EdgeEver 插件市场填写仓库地址：

```text
https://github.com/ZhenYu-Jiang/edgeever-web-clipper
```

## 使用

1. 用命令「网页收藏」打开面板，粘贴文章链接，点击 **提取正文**。
2. 核对正文预览、字数和图片数量，可修改笔记标题并选择目标笔记本。
3. 点击 **保存正文**，完成后可直接打开笔记。自动添加「收藏」标签。

已有用户在插件管理中检查更新到 **1.1.0**。插件 ID、仓库地址和命令保持不变；新增 `ui:navigation` 能力用于打开刚保存的笔记。

## 这版解决了什么

旧版仅读取网页的 `description` 元数据，收藏结果常常只有一句摘要。1.1.0 使用 Mozilla Readability 提取文章主体并转换为 Markdown，保存前提供可阅读的预览；不会再把自动降级的摘要当成正文直接保存。

- **完整内容优先**：不设截取前几段的逻辑；保留提取出的全部文章内容，包括相对链接、常见懒加载图片和代码语言标记。
- **预览后保存**：抓取本身不创建笔记，选择标题和笔记本后再保存。同次预览不会因重复点击生成多篇笔记。
- **抓不到正文时**：提示原因，可以从原网页复制正文，展开「抓取不完整？粘贴正文」生成预览。也可以明确选择「仅收藏链接」，保存时会注明未提取正文。
- **RSS / Atom**：可以对条目「提取全文」，也可「预览订阅内容」。订阅摘要与订阅正文分开标识，保存摘要时明确注明。支持 `content:encoded` 和 Atom alternate 链接。
- **失败可恢复**：取消读取、切换链接和关闭面板后，旧请求不会覆盖新结果；保存失败时保留预览，笔记本列表支持刷新。

## 支持范围

- 抓取公开 HTTPS 页面（443 端口），省略协议的域名会补为 HTTPS。尊重宿主公开网络接口的 2 MB 响应限制；超限会提示，不会悄悄截断内容。
- 需要登录、订阅权限、验证码或大量前端脚本生成的内容，未必能从公开 HTML 中提取；本插件不会读取浏览器登录态。可使用手动粘贴正文。
- 图片以原站 URL 保存在笔记中，不下载到附件库；原站防盗链或链接失效会影响显示。预览只显示图片占位，不自动请求图片。
- 阅读模式提取可能忽略网站自定义组件、多页文章或复杂排版；保存前请核对预览。PDF、视频等文件使用附件导入。

## 开发与测试

```sh
npm ci
npm run build
npx playwright install chromium
npm test
```

修改 `src/` 后重新构建；`main.js` 是提交到仓库的单文件分发包，无外部运行时依赖。第三方许可随包内嵌，并列于 `THIRD_PARTY_NOTICES.txt`。

13 项隔离浏览器测试覆盖长文章末段、格式转换、预览安全、RSS/Atom、跳转、GBK 编码、取消与竞态、保存失败、大小限制和窄屏。测试使用模拟宿主接口，不读取真实笔记，也不声称覆盖所有网站。

发布时推送与 manifest 版本一致的标签。GitHub Actions 构建、测试通过后发布三个分发资产；主分支也能补发已打标签且分发文件一致的未发布版本，已有 Release 不会被覆盖。
